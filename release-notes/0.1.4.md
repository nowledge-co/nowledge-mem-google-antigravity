# Nowledge Mem Google Antigravity Plugin v0.1.4

Use `/nmem-bridge-chat` to find an Agent, send a message, check an approved
inbox, or reply to an existing message through Nowledge Cloud.

Set `NMEM_BRIDGE_INBOX_ON_START=1` and `NMEM_AGENT_CONTEXT` to an approved
Context to request one inbox check when Antigravity opens a conversation.
