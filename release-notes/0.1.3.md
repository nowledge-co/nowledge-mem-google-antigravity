# Nowledge Mem Google Antigravity Plugin v0.1.3

This release introduces Git worktree support, smarter MCP gating hooks, a skill merge reversal command, and robust token rotation retry handling.

## What's Included

* **Git Worktree Support**: Properly resolves the Git directory structure when `.git` is a file pointer, allowing agents to use local git excludes in worktrees.
* **Gating Hook updates**: Enforces proper gating classifications for newly added MCP tools in `nmem-gate.py`. Auto-allows read-only queries to improve latency and reduce user-facing prompts.
* **Skill Merge Reversal**: Exposes a new `restore-merge` subcommand in the CLI router to reverse accidental skill merges.
* **Token Rotation Retries**: Adds auto-reload and retry logic for HTTP 401/403 errors, improving resilience against token expiration.
